# LinkLighter 🔗✨

**LinkLighter** is a simple Chrome extension that highlights all clickable links and buttons on any webpage with a single click.

## Features
- Highlight all `<a>`, `<button>`, and clickable elements.
- Toggle highlighting ON/OFF easily.
- Clean and lightweight.

## Installation

1. Download this repo.
2. Go to `chrome://extensions/`.
3. Enable **Developer Mode**.
4. Click **Load Unpacked** and select the `linklighter/` folder.

## Usage

- Click the LinkLighter icon to highlight all clickable items on a page.
- Click again to remove the highlights.
